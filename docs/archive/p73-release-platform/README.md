# Archived: P73 release-platform design (retired 2026-10-20)

These documents describe a retired design for P73 versioning and packaging: a production sandbox supervisor, Git auditor, evidence engine and artifact manifest, plus the development sandbox harness built to implement it. None of it was implemented in this repository. The design was retired after a churn audit (external evidence: `/Users/ivan/ws/limitaur-review/2026-10-20-release-tooling/implementation/churn-audit.md`) found that it had grown from "add a version number" into a general release-qualification platform.

Internal relative links between these files may be broken by the move. They are kept as history and as a warning, not as instructions. The replacement scope is the minimal versioning described in `docs/handoff.md`.
