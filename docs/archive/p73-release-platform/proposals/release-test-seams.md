# P73 import-only filesystem test seams

Pre-implementation clarification, 2026-10-20. Required before independent freeze. Original/v2 bytes remain unchanged. These minimum internal exports make the already-required real filesystem/Git boundary tests reachable without a fully qualified prepare fixture. No CLI, manifest/evidence, reason-code, permission or release-gate change. They live in release_support.py with implementation/common routines in the existing three-file TCB; final code/data review and first normal-user execution gate remain.

- `read_input_file(root:pathlib.Path,relative:str,*,max_bytes:int=1048576)->bytes`: no-follow absolute-root/member descriptor traversal; regular/link-count1 only; O_NONBLOCK; before/after metadata checks. Relative names are NFC, at most1024 UTF-8 bytes, nonempty, with no absolute/empty/dot/dotdot component or invalid Unicode. Bound max_bytes to integer1..268435456, bool rejected. Unsafe/missing/non-directory/symlink absolute root/components: unsafe_path. Unsafe/missing/symlink/FIFO/special/multilink/oversized member or invalid relative/limit: unsafe_input. No decoding/JSON parsing or tool execution.
- `hash_artifact_tree(root:pathlib.Path)->dict`: same safe root and no-follow bounded tree walk; original root/entry modes, NFC/case-fold collision, regular/link-count1, size/depth/entry and hash rules. Return exactly `{rootMode:INT,entries:LIST,sha256:HEX}`; sha256 hashes canonical `{rootMode,entries}`. This primitive hashes bounded data, without requiring Mach-O, plist/signature validity or minimum app layout; higher validators/workflows enforce those. Unsafe root: unsafe_path; unsafe tree/member/limits: unsafe_input. No tool or candidate execution.
- `audit_git_source(repo:pathlib.Path,services:Services)->dict`: original strict metadata/config/index/cleanliness/raw-blob audit using the prescribed fixed Git prefix/queries. Return exactly `{sourceCommit:OID,sourceTree:OID,sourceFilesSHA256:HEX,repositoryConfigSHA256:HEX}`. The source digest is canonical tracked `{relativePath:{mode,sha256}}`. This generic inert-repository primitive does not require Limitaur's inventory, app layout, VERSION/changelog policy, tool tuple or release evidence. Prepare/verify retain all higher project/freeze/version/input checks. Unsafe root: unsafe_path; unsafe metadata/selected input type/link: unsafe_input; unsupported configuration/index flags/repository mechanism: source_unsupported; dirty/raw mismatch: source_dirty/source_changed as applicable. Allowed content-addressed object links remain allowed. No Git write, checkout/filter, fetch/helper, package/test/app execution or metadata mutation.

Production prepare/verify use these functions or the same underlying descriptor/audit implementation; no test-only duplicate/fallback that bypasses production behavior. CLI still constructs real Services and resolves its own repository root, with no test-service/root override. Verify remains read-only and never provisions a volume.

Independent tests assert targeted reader/tree/Git failures through these primitives on real harmless data. Their incomplete invented verify fixtures may assert safe rejection/read-only effects, but must not require an unrelated specific failure order or claim the targeted boundary was reached through an earlier failure. No successful prepare/verify lifecycle is fabricated. Source/artifact mismatch policy and full positive/negative verify decisions remain driver acceptance checks after frozen-TCB execution approval. No required acceptance case or frozen old test is removed.
