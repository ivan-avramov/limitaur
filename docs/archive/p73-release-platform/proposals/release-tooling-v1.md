## Version and app behavior

VERSION initially contains0.1.0 plus LF. Maximum4096 raw ASCII bytes INCLUDING an optional single terminalLF. SemVer2 grammar: three canonical decimal core components; optional dot-separated prerelease/build identifiers using ASCII alphanumeric/hyphen; numeric prerelease identifiers have no leading zeros, build identifiers may. Keep numeric components as strings. Reject BOM, CR, whitespace, extra LF/lines, non-ASCII, empty identifiers and bad characters. Use the existing immutable version-vectors.json plus raw-length boundaries.

A local build-tool plugin declares root VERSION as an input and generates full/core Swift constants in plugin scratch. Ordinary swift build/test must regenerate after VERSION changes; no checked-in generated source or runtime VERSION read. Generator has the Swift parser; do not add a second runtime parser just for testing. Python packaging validates the same grammar. Driver exercises the real generator against shared vectors and real incremental builds.

Exactly Limitaur --version prints full SemVer plus LF and exits0 before NSApplication/settings/credentials/monitor/transport. Extra arguments use the existing fixed diagnostic/exit2. App help lists --version. Append About Limitaur… after existing Settings items, preserving indices0/2 and the8-indicator submenu. Production About options explicitly set applicationVersion to the compiled full SemVer; version is the app bundle build number when available and omitted for unbundled/non-app test bundles. About causes no auth, refresh or preference writes. Tests inject the presentation callback; actual dialog/UI inspection remains a later gate.

## Source and process boundaries

This tool supports a trusted developer-owned checkout, not hostile repositories or hostile concurrent writers. Set no-optional-locks, disable fsmonitor/hooks/untracked cache/auto-maintenance and lazy fetch/replacements; ignore global/system Git configuration and set core.excludesFile/core.attributesFile=/dev/null. Strip ambient Git overrides; set GIT_CEILING_DIRECTORIES to the root parent and require rev-parse --show-toplevel to equal the physical selected root. Do not implement object/index/config auditing. Declare that local Git configuration is part of the trusted checkout assumption; this is not a hostile-Git security claim.

The snapshot is exactly {schemaVersion:1,version:FULL,coreVersion:CORE,buildNumber:TEXT,buildNumberOrigin:explicit|git-count,sourceCommit:HEX,sourceStatus:git-clean|git-dirty,sourceInputsSHA256:HEX}. sourceInputsSHA256 hashes canonical sorted {trackedRelativePath:{mode:permissionBits,sha256:HEX}} for actual current tracked regular files. Use stage-0 ls-files --stage -z entries. Reject unmerged entries, gitlinks, tracked symlinks, missing tracked files as unsafe_input (no general index parser). Snapshot actual bytes/modes before and after reads; reject symlinks, special/multilink files, invalid/traversing/non-NFC paths, mode special bits and observed changes. Bound tracked inputs to4096 files,16MiB/file and128MiB total; relative paths<=1024 UTF8 bytes and depth<=16. No ignored/untracked file contents are copied or hashed. Source digest records tracked inputs, not every possible toolchain/plugin/environment input. Recompute before packaging and before publication; observed source/HEAD/status/count changes fail. No hostile race or reproducible-build claim.

Accept known /tmp-to/private/tmp and /var-to/private/var prefix aliases component-wise; reject unsafe/dot components before translation and all other selected-root/ancestor/leaf symlinks. The wrapper uses pwd -P for its own repository and TMPDIR and passes absolute paths; it must not silently resolve a user-output symlink into an accepted destination. Use nonblocking nofollow descriptor reads, qualified Darwin search-only ancestor traversal, bounded enumeration and streaming hashes. Final directories needing enumeration must be readable. Do not read-open temp ancestors or relax the harness profile. Selected input/root symlinks are rejected; ordinary spaced/NFC paths work. Internal cleanup checks owned inode/device identity and uses retained parent descriptors, never path-based deletion through substituted ancestors.

All helper child queries/codesign checks use bounded while-reading stdout+stderr (32MiB combined), known process groups and deadlines: query30s, sign/verify60s. ## Packaging, identity and inspection

Validate VERSION and CHANGELOG before building. CHANGELOG.md is UTF8, LF-only and <=1MiB. It always has exactly one ## [Unreleased] section; every other level-two heading must be a dated release heading below, with no chronological-order requirement. Dated headings, if present, are ## [FULL_SEMVER] - YYYY-MM-DD, unique by full version and with a real calendar date; no current dated heading is required for development packaging. Changelog is proposed notes, not publication evidence.

Info.plist is a template with no independently authored version: CFBundleShortVersionString=core, LimitaurSemVer=full, LimitaurSourceRevision=HEAD, CFBundleVersion=normalized build number. Preserve LSUIElement=true, identifier/executable/name, minimum26.0 and existing app settings. Package one executable and ordinary required directories/plist/ad-hoc CodeResources. No dependencies/helpers/frameworks embedded or new runtime dependencies.

Refuse any existing output app OR sidecar, including a symlink; preserve their bytes. Sidecar path is APP.manifest.json. Create staging exclusively under the existing output parent, on the same filesystem; only the default repository dist component may be safely created if absent, never arbitrary ancestor chains. Reject selected-root/ancestor symlinks. Copy a regular single-link executable with bounded nonblocking reads and before/after identity/size checks. Sign ad-hoc, codesign --verify --strict and validate plist. Packaging never executes the input/copied app; the development driver compares the actual bundled --version to VERSION only after the staged-artifact guard controls qualify. Recheck source and app after tools. Signature/dependency/deployment release qualification and compiled-version proof are not inferred merely from these packaging checks.

Publish app and sidecar with no-overwrite filesystem operations. They are individually exclusive, NOT an all-or-nothing two-path transaction. If sidecar publication fails after the app was published, retain the app, return failure with fixed stderr partial_output followed by the fixed underlying error code; do not delete a published app or overwrite the conflicting sidecar. The caller must inspect/resolve that state. Clean only owned unpublished staging on every ordinary exit; cleanup failure is failure. No self-provisioning supervisor or general publication protocol.

Manifest generation and inspection require canonical UTF8 JSON (Python json.dumps with sorted keys, compact separators, ensure_ascii=false, allow_nan=false, then one terminalLF), at most1MiB. All source/artifact digest preimages use those exact canonical bytes INCLUDING that LF; mode is an integer permission bitmask. artifact_digest.sha256 maps directly to artifactTreeSHA256. An over-cap generated manifest fails invalid_manifest before publication. Exact keys: schemaVersion=1, build=SNAPSHOT, executableSHA256, artifactRootMode, artifactEntries, artifactTreeSHA256. Entries are relative to APP and bytewise sorted: {path,type:directory,mode} or {path,type:file,mode,size,sha256}. Root mode separate; tree digest hashes canonical {rootMode,entries}. Require unique NFC/component-safe paths, no Unicode casefold collisions, modes0..0777 and regular single-link files only; no symlinks/special files. Limit4096 entries, depth16,256MiB/file,512MiB total. Hash actual CodeResources and all app entries. executableSHA256 matches Contents/MacOS/Limitaur. The manifest is outside its own hashed app tree.

inspect rejects duplicate/unknown/missing JSON keys, bad types (bool is not int), bad bounds/hashes, inconsistent plist/source/executable/tree, extra/mutated entries and unsafe paths. Compare build to current source metadata, verify signature and bracket path-based tool calls with unchanged artifact/root/member checks. No candidate execution. Manifest is unsigned consistency metadata, not authenticity or evidence of UI/provider/performance success. No custom Mach-O parser, fat-binary support, SDK/toolchain attestation or generic evidence schema. Document these limits directly.
