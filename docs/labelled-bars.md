# Labelled bars addendum

Approved 2026-10-20 (P323–P327), revised 2026-10-21 (P331–P339). Supersedes only the bar geometry paragraph of docs/compact-bars.md. Ranking, counts 1–8, thresholds, tint, dropdown, tooltip and accessibility are unchanged.

- Active layout, "beside": each slot is a 5 pt bar, 18 pt high, with two codes stacked to its right in the menu-bar foreground colour: the provider code (two letters, docs/provider-codes.md) above the window code. Slot 19 pt, gap 5 pt; width is 19n + 5(n−1) + 12.
- Retained for comparison, selectable only in code (`RingView.layout`): "jar", an 18×20 pt jar with the codes painted inside in a contrast colour; "logo", the provider image used as the gauge shape with the window code centred, falling back to jar without an image. Neither is shipped as default; the operator asked to keep them for now.
- Track is opaque and follows the appearance: grey 0.42 in dark mode, 0.6 in light mode, so the foreground-tinted fill contrasts with it and nothing behind the status item bleeds through. Fill colours unchanged: foreground tint, yellow >80, red >95.
- Window code, derived by `windowCode(for:)` from the metric alone, never from plan. A known duration decides first: `5` ≤6 h, `W` exactly 7 d, `M` 28–31 d, `?` any other duration. Without a duration the decoder kind decides: `5` session/five_hour (and legacy five_hour_*), `W` weekly/weekly_all/weekly_scoped/seven_day (and legacy seven_day_*), `$` spend or metered; then whole-word label hints; `?` otherwise, never blank. A modern model-scoped limit with a display name adds `scopeInitial(for:)` as a second character, so Fable's weekly limit reads `WF`.
- Provider code is `providerGlyph(for:)` from the `providerCodes` table; a monochrome template image at `Resources/providers/<providerID>.png` replaces it in the jar layout only. The repository never contains such images; `Resources/providers/` is ignored and the build script copies them if present.
- Unavailable slots keep the neutral dash and carry no codes. Health marker unchanged.
- Signing: `scripts/build-app.sh` signs ad-hoc unless `LIMITAUR_SIGN_IDENTITY` names a code-signing identity, which keeps the Keychain's trust across rebuilds (P339).
